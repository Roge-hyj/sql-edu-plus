# 优化问题清单

本清单从优化前基线开始维护。每个条目完成时必须同时补充代码变更、测试、证据和回滚说明；不同门禁不合并成一个无法定位的“大重构”。

## P0：阻断学生试运行

- [x] `SEC-001` 生产 SQLAlchemy engine 改为配置控制，默认 `DB_ECHO=false`，并有回归测试。
- [x] `SEC-002` CORS 改为 `BACKEND_CORS_ORIGINS` 白名单，移除通配来源并收紧方法/请求头。
- [x] `SEC-003a` `/mail/test` 默认不注册；仅显式 `ENABLE_MAIL_TEST=true` 的开发/staging 环境启用。
- [ ] `SEC-003b` 验证码接口仍缺少明确的限流、防滥用和重放策略。
- [ ] `SEC-004` 教师邀请码 `ILOVESQL` 硬编码，需要改为安全配置或教师账户 provisioning。
- [ ] `DB-001` 统一 Phase 1 冻结使用的 MySQL 版本与运行目标版本，并完成当前完整 Alembic head 的升级、回滚、恢复演练。
- [ ] `P1-001` 明确方言、数据库版本和支持的 SQL 特性契约。
- [ ] `P1-002` 分析并修复 v16 的 22 个确定性 mismatch。
- [ ] `P1-003` 分析并修复 v16 的 7 个 parser/input generation gap。
- [ ] `P1-004` 用新的 hidden 快照重新冻结，要求 generation failure=0、determinate mismatch=0、重复运行稳定且 `acceptance.pass=true`。
- [ ] `WORKER-001` 将 Phase 1 从不可强杀的 `asyncio.to_thread` 迁移到可强制终止的进程/Worker，并增加队列、CPU、内存、超时和重建门禁。
